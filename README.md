# FUTURE_PE_03 – AI SEO Content Cluster Generator

## Project Overview

This project was created as part of the Future Interns Prompt Engineering Internship.

The goal of this task was to design an AI-powered SEO content cluster strategy for a local business using structured prompts and AI-generated content.

## Business Chosen

GlowUp Beauty Salon, Mumbai

## What This Project Includes

* Local SEO keyword strategy
* Pillar blog
* Supporting SEO blogs
* Content cluster strategy
* Internal linking strategy

## Tools Used

* ChatGPT
* GitHub

## Skills Demonstrated

* Prompt Engineering
* SEO Content Strategy
* Local SEO
* AI Content Generation
* Content Clustering
* Website Content Planning

## Outcome

This project demonstrates how AI can be used to create scalable SEO strategies and website-ready content for real local businesses.
